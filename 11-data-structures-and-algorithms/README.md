# Phase 11 — Data Structures and Algorithms

## Why DSA Matters for a Java Developer

Every production system handles data at some scale. The difference between a service that handles 1 million requests per day and one that falls over at 10,000 is often a single poor data structure or algorithm choice. Understanding DSA lets you:

- **Choose the right data structure** — knowing why `HashMap` is O(1) lookup but `ArrayList` is O(n) lookup changes how you design code.
- **Spot performance problems early** — recognising that a nested loop over a large dataset is O(n²) is the first step to fixing it.
- **Solve technical interview problems** — DSA is the primary focus of software engineering interviews at most companies.
- **Write correct algorithms** — sorting, searching, and graph traversal appear in real production code.
