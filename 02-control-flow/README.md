# Phase 02 — Control Flow

Control flow determines the ORDER in which statements are executed. By default, Java runs code top to bottom, one line at a time. Control flow lets you make decisions (if/else), repeat actions (loops), and choose between options (switch).

## What You Will Learn
- Making decisions with if, if-else, else-if
- Choosing between options with switch
- Repeating actions with for, while, do-while loops
- Skipping or stopping loops with break and continue

## Prerequisites
Phase 01 — Java Fundamentals (variables, operators, data types)

## Learning Goals
After completing this phase you should be able to:
- Write programs that make decisions based on conditions
- Use all three loop types and choose the right one
- Read and trace nested control flow
- Avoid common bugs like infinite loops and off-by-one errors
